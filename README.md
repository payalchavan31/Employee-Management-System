# Employee Management System

## Project Description
Employee Management System is a Core Java
project developed using Object-Oriented
Programming (OOP) concepts and Collections.

## Features
- Add Employee
- View Employee Details
- Update Employee Details
- Delete Employee

## Technologies Used
- Java
- Core Java
- OOP Concepts
- Collections

## Concepts Implemented
- Encapsulation
- Inheritance
- Polymorphism
- ArrayList and Collections
